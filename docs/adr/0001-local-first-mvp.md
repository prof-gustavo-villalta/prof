# Local-first MVP

The MVP stores aulas, turmas, alunos and chamadas on the device first, because attendance must work reliably in a classroom even without internet. Cloud sync and backup are deferred until the local attendance flow is proven useful.

## Considered Options

- Local-first storage for the MVP.
- Cloud-backed storage from the beginning.

## Consequences

- The first version must be useful offline.
- Cross-device sync, backup and account login are outside the initial scope.
