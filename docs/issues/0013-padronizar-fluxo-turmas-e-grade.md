# Padronizar fluxo Turmas e Grade

## What to build

Padronizar o fluxo de **Turmas** e **Grade Semanal** para seguir o **Design System**. A experiencia de listar turmas, ver detalhes, gerenciar alunos e editar aulas da grade deve preservar as regras atuais e ficar visualmente consistente com as telas simples ja padronizadas.

## Acceptance criteria

- [x] A lista de Turmas usa componentes e tokens do Design System para listas, empty states, acoes e divisorias.
- [x] O detalhe da Turma usa componentes e tokens do Design System para secoes, alunos e acoes.
- [x] A Grade Semanal da Turma usa componentes e tokens do Design System para linhas, status e empty states.
- [x] O formulario de Aula da Grade usa componentes e tokens do Design System para campos, seletores e acoes.
- [x] Nao ha regressao em cadastro, edicao ou remocao de Turmas, Alunos, Disciplinas ou itens da Grade Semanal.
- [x] `flutter analyze` passa.
- [x] `flutter test` passa.
