# Padronizar telas simples e forms

## What to build

Padronizar as telas simples e formularios para usarem os componentes e tokens do **Design System**. As telas devem manter o mesmo fluxo para o professor, mas com layout, campos, cards, botoes e espacamentos consistentes com o restante do app.

## Acceptance criteria

- [x] A tela de Ajustes usa componentes e tokens do Design System para cards, texto, icones e espacamento.
- [x] O formulario de Turma usa componentes e tokens do Design System para campos, secoes e acoes.
- [x] O formulario de Disciplina usa componentes e tokens do Design System para campos, secoes e acoes.
- [x] Nao ha regressao nos fluxos de criacao ou edicao dessas entidades.
- [x] `flutter analyze` passa.
- [x] `flutter test` passa.
