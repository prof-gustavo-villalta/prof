# Chamada aberta com lista vertical e autosave

## What to build

Implementar a **Chamada aberta** de uma **Aula** com lista vertical mobile-first em Web e Android. A chamada deve comecar com todos os **Alunos** em **Ausencia**, salvar automaticamente cada marcacao e permitir fechar a chamada. Tocar no Aluno marca **Presenca**; opcoes secundarias permitem **Atraso** e **Justificativa**.

## Acceptance criteria

- [ ] Uma Aula pode ter no maximo uma Chamada.
- [ ] Ao iniciar uma Chamada, todos os Alunos da Turma comecam em Ausencia.
- [ ] Tocar no card do Aluno alterna Ausencia para Presenca.
- [ ] O card permite escolher Atraso ou Justificativa como opcoes secundarias.
- [ ] Cada mudanca de status e salva automaticamente.
- [ ] A lista de chamada e vertical em Web e Android.
- [ ] A lista tem busca por nome e filtros: Todos, Presentes, Ausentes, Atrasos e Justificados.
- [ ] Fechar a Chamada confirma as Ausencias restantes e cria uma Chamada fechada.
