# Base local-first e navegacao mobile-first

## What to build

Construir a base do app pessoal do **Professor** para Web e Android, sem login, com persistencia local e navegacao principal em portugues: Hoje, Turmas, Historico e Ajustes. A primeira tela deve substituir o contador padrao do Flutter por uma estrutura visual mobile-first inspirada em Any.do, com fundo claro, espaco em branco, cartoes limpos e uma acao principal evidente.

## Acceptance criteria

- [x] O app abre em Web e Android com a navegacao principal: Hoje, Turmas, Historico e Ajustes.
- [x] O app nao exige login, senha ou PIN.
- [x] Existe uma camada de persistencia local pronta para armazenar dados do MVP.
- [x] A interface usa portugues do Brasil e os termos canonicos do dominio.
- [x] A tela inicial nao mostra mais o contador padrao do Flutter.
- [x] Ha teste ou verificacao automatizada cobrindo o bootstrap basico do app.

## Blocked by

None - can start immediately
